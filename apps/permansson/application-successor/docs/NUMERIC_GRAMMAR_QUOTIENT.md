# Exact finite grammar and induced-Markov quotient — numeric contracts

These are **two bounded numerical/checker capabilities**, not new mathematical certificates. They never claim a kernel-checked Lean proof, independently accepted mathematical closure, an empirically identified strategic generator, Exact GR/PR status or an authorized release. Their strong scientific certificate fields remain unassessed.

## Explicit admitted-block intervention grammar

CLI: `permansson-app finite-grammar grammar.v1.json --output result-grammar`.

Input has one fully reified finite strategic-world `alpha/P/U` baseline, one to eight named complete-row `alpha` or `U` patches, a **predeclared list of at most 32 admitted component blocks**, a region and complete comparison states, horizon 0–16, and optional typed alpha/U four-corner comparisons. `P`, feasibility, state and action inventories are held fixed. Patches that overlap must assign identical complete probability rows when the relevant joint block is admitted; all probabilities are exact rationals.

Every declared block is reconstructed against the **original actual model**. The receipt lists the finite-horizon survival/exit value and signed difference from baseline for **every** comparison state, whether each block has a uniformly positive effect over the entire declared comparison set, all inclusion-minimal positive admitted blocks, and exact four-corner interaction `F(a,u)-F(a)-F(u)+F(empty)`. The checker independently rebuilds each original-model row and induced joint atom law, then recomputes values and minimality. Admission is not downward closed: a joint-only admitted block does **not** authorize its singletons; four-corner assessment requires all four separately admitted configurations.

This is a finite, model-relative effect diagnostic. Finite horizon or a positive score does **not** establish Exact GR, grounded constitutive PR status, causal identification or relevance of a decorative state.

## Intervention-family exact typed quotient

CLI: `permansson-app finite-quotient quotient.v1.json --output result-quotient`.

The input declares finite strategic and world-state coordinates, a surjective map on **each type**, and one to eight complete, explicitly typed strategic interventions. The quotient must strictly reduce the number of joint states, and must be strongly lumpable for the **baseline and every intervention**: every fine state within a given coarse fiber must have exactly the same aggregated transition probabilities into every target fiber. A baseline-only or accidental one-state agreement is rejected. Only `alpha`, `U` and `alpha+U` can change; `P` and feasibility must remain byte-semantically fixed.

Both the region and comparison state sets must be complete unions of whole fibers. Every fine and coarse finite-horizon survival/exit value and intervention-versus-baseline difference is computed exactly; an independent checker reconstructs the original joint law directly as `Σ_a alpha(s,x,a) P(x'|s,x,a) U(s'|s,x,a,x')` and independently verifies every fiber, value and effect.

**Limit:** this is an exact quotient of the induced **Markov law** under a type-respecting state map. It neither constructs nor proves an independent coarse `alpha/P/U` factorization. It does not establish the whole Exact-GR/PR transport theorem or theorem-level intervention correspondence in Lean. No approximate quotient or error bounds are offered under this profile.

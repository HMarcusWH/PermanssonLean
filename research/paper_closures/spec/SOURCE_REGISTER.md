- Official mathlib kernel Radon–Nikodym documentation: https://leanprover-community.github.io/mathlib4_docs/Mathlib/Probability/Kernel/RadonNikodym.html . The agent must inspect the **pinned** version before selecting instances; online documentation is not a compiled compatibility check.
- Official mathlib matrix adjugate documentation: https://leanprover-community.github.io/mathlib4_docs/Mathlib/LinearAlgebra/Matrix/Adjugate.html . Used to locate reusable determinant/inverse APIs, not to assert a new stationary constructor already exists.

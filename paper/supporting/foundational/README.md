# Foundational supporting theory

This directory contains the direct theoretical predecessor of **Permansson Regimes: A General Framework for Strategic Dynamics Beyond Equilibrium v0.1.8**.

## Hermansson (2026a)

- [**Equilibrium-Generated Regimes and Constitutive Regime Formation: A Post-Equilibrium Classification of Dynamic Games**](EGR_Core_Paper.pdf) — Working Paper v1.2.2, 1 August 2026.

This is the Paper-I / EGR framework embedded and conservatively recovered by the generalized GR/PR construction in v0.1.8. It supplies the equilibrium-generated regime object and the intervention-relative Permansson-regime concept that the later paper generalizes beyond equilibrium as a primitive of the regime layer.

The file is included here as a repository-hosted supporting paper. Its presence does not change the frozen v0.1.8 release-package hashes or the immutable Lean formalization snapshot.

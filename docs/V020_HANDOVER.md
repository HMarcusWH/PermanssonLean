- **Toolchain.** Run `export PATH=$HOME/.elan/bin:$PATH` first. `lake build PermanssonResearch` takes about 10 min warm. The first build after a container restart spends several minutes re-reading oleans from cold disk with no CPU use; that is not a hang.

- **Worktrees** are useful for working on two lanes at once without disturbing a running review:

  - The repo workflows trigger `pull_request` only for base `main`. Stacked PRs therefore need `workflow_dispatch` runs of `research-lean.yml`, `lean.yml`, `verification.yml` and `application.yml` on the branch, through `mcp__github__actions_run_trigger`.

- **Pitfalls hit this session:**

  - Measures as Python dicts: compare **normalized** dicts, dropping zero atoms.

### Objectives to formalize, in this order

1. **D2.1 / D2.2: reach-by-horizon before forbidden,** `P(τ_G ≤ T, τ_G < τ_D)`.
   - D1 already proves this for finite fully observed controlled families, so reuse it. D2 should only connect or package it (no re-proof) and state the remaining scope.
2. **D2.3: reach-and-stay for a declared duration `m`.**
   - Use a product or clock state `(y, k)`, with `k` counting post-entry residence.
   - The new Bellman recursion is `V_{t+1}(y, k) = max_c Σ K_c(y, z) V_t(z, k')`, where `k' = k+1` if `z ∈ G` and `k > 0`, and `k' = 0` if the run leaves `G` before completing `m`. The terminal value is `1[k = m]`.
   - Prove that the recursion's value equals the probability of the genuine path event "enter `G` by `T` and stay `m` steps", through the canonical event machinery.
   - **Hit ≠ stay witness:** a two-state chain where `G` is hit with probability 1 but immediately exited, so the stay-1 probability is 0.
3. **D2.4: eventual switching.** Consume C69.4 (countable routing) and C70 (random-entry occupation) rather than re-proving them.
   - Shape: `P(eventually enter B'_0, then remain forever) ≥ 1 − η` ⇐ routing bound + post-entry Exact-GR invariance of the target.
   - See `RegimeExit/SwitchRouting.lean` (`switch_first_exit_event_lower_bound`, `SwitchRoutingBound`), `ExitLawLimits.lean`, `StoppedFutureRestart.lean`, and on #70 `Proposition42f.lean`.
   - Not "a hit is a stay".
4. **D2.5: robust objective separation.**
   - Give an explicit finite example with `sup_π inf_K P^{K,π}(success) < inf_K sup_π P^{K,π}(success)`. For example, two models `K₁, K₂` and two controls `a, b`, where `a` succeeds only under `K₁` and `b` only under `K₂`: sup-inf = 1/2 with randomization, or 0 deterministically, while inf-sup = 1.
   - State the quantifier order, observation structure and rectangularity, and write **no** robust Bellman recursion without rectangularity.
5. **Python exact tests:**
   - hit ≠ stay;
   - stay recursion equals path enumeration on small chains;
   - sup-inf < inf-sup;
   - constrained risk budget: max-success Bellman ≠ constrained optimum, per architecture §7.4 "Hard risk budgets".

## How to interpret evidence

Source existence, a literal citation, a grouped reading route, a manuscript proof, a Lean compiler run, an exact calculation, independent acceptance and empirical identification are separate fields. The [residual-status page](RESIDUAL_STATUS.md) is the current scientific-status authority in this documentation layer. Historical case ledgers, guide edition files and release receipts retain their own identities and are not silently updated by a new chapter or link.

The [seven exposed edition indexes](../../paper2/v2.0.1/indices/) are exact copies from the reviewed source/concordance package. Larger extraction inventories remain inside that package. The [verification guide](VERIFICATION.md) explains how to check them and the limits of each check.
